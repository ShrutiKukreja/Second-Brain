# Claude Bootcamp (Build Production-Ready AI Products & Crack AI Interviews)

The secondary Maven course from [[agentic-ai-institute]], taught by [[mahesh-yadav]]. Lighter-weight than the [[agentic-ai-pm-certification]] (~6 hrs/week vs ~18 hrs/week), combining hands-on Claude Code building with AI PM interview preparation. Can be bundled with the main certification for full coverage.

## Curriculum

1. **Foundations** — Claude Code setup, "Super-IC PM" mindset, Research Copilot build, 2026 job landscape
2. **Technical Depth** — full-stack AI product dev, spec-based development (see [[spec-based-development]]), AI memory/security/observability
3. **Agents at Scale** — scheduled learning loops, Snowflake + Claude skills data pipelines, multi-agent deployment on Azure AI Foundry
4. **AI Security & Safety** — red-teaming, prompt injection defense, Anthropic-grade security
5. **AI PM Interview Mastery** — MAANG/OpenAI/Anthropic frameworks, live mock interviews, CV refinement

## What's Included

14 live sessions, hands-on labs (personal AI assistant, full-stack app, job search automation, data pipelines, Azure AI Foundry deployment), guest sessions (Charu Agrawal of RoleStack.ai, Brian Kemler ex-Meta/Google), 6 live mock interviews, 21-day daily AI PM question track, 3 months access to Mahesh's miniPM agent and skills.md toolkit.
