# Claude Code

Anthropic's agentic coding tool, used throughout [[agentic-ai-institute]]'s curriculum as the primary hands-on building environment — most heavily in the [[claude-bootcamp]], which is named after it.

## Why It Matters (per this corpus)

- "Claude Code Just Changed Everything (Agents Can Now Access Your Files)" (YouTube, 2026-03-18) — earliest video in the corpus flagging Claude Code as a step-change for agent-file access.
- Framed as necessary-but-insufficient for landing an AI PM job: a LinkedIn post (2026-07-28) notes a candidate "could build a solid AI prototype in Claude Code but didn't get the offer — no monitoring, no guardrails, no deployment story."
- Central to [[spec-based-development]], where the risk of un-spec'd Claude Code usage ("one change upstream breaks everything downstream") is explicitly called out.

## Where It's Taught

The [[claude-bootcamp]] curriculum uses Claude Code across nearly every week:
- Week 1: Claude Code workspace setup, Research Copilot build
- Week 2: full-stack AI product dev, spec-based development, AI memory/guardrails/observability
- Weeks 3–4: Snowflake + Claude skills data pipelines, Azure AI Foundry deployment
- Free public series: "Build and Ship with Claude Code" (3 sessions — spec-driven building, data pipelines, Azure AI Foundry deployment)
